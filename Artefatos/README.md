# Artefatos do Projeto

Este diretório mantém os artefatos produzidos ao longo do projeto. Liste os artefatos com suas localizações e descrição do conteúdo.

## Exemplos de organização

**Artefatos de gestão e reuniões:**

* `/atas` — Atas de reunião.
* `/canvas` — Canvas de definição do problema, proposta de valor ou modelo de negócio.
* `/cronograma` — Planejamento, entregas e acompanhamento das atividades.

**Artefatos técnicos:**

* `/diagramas` — Diagramas de arquitetura, pipeline de dados, fluxo do sistema ou modelo entidade-relacionamento.
* `/experimentos` — Registros de execuções, hiperparâmetros, métricas e comparações entre modelos ou abordagens.
* `/prototipos` — Protótipos de interface, dashboards ou fluxos de interação, quando aplicável.

**Outros:**

* Crie diretórios conforme os artefatos exigidos pela disciplina e descreva-os neste arquivo.
