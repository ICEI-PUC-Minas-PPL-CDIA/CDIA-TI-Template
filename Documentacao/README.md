# Documentação do Projeto

Use este diretório para arquivar a documentação escrita produzida ao longo do projeto. As especificações e entregas exigidas por cada disciplina são definidas pelos professores no Canvas — este diretório é apenas onde a equipe guarda os documentos correspondentes.

Esta pasta pode conter, por exemplo:

* Relatórios parciais ou finais.
* Descrição da metodologia utilizada (ex.: etapas da análise, desenho experimental, validação do modelo).
* Registros de decisões técnicas relevantes.
* Manuais de uso, instalação ou configuração.
* Outros documentos solicitados pelos professores.

Se forem mantidas várias versões de um relatório, use nomes claros, datas ou identificadores de entrega para facilitar a rastreabilidade.
