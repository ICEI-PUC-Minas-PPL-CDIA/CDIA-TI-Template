# Divulgação do Projeto

Use este diretório para arquivar os materiais de divulgação do projeto, conforme as orientações da disciplina.

Esta pasta pode conter apresentações, vídeos, imagens, capturas de tela, banners, pitch, pôster, roteiro de demonstração, material para redes sociais ou outros arquivos usados para comunicar o projeto e seus resultados.

Crie subdiretórios conforme a necessidade da equipe ou exigência dos professores, por exemplo:

* `/apresentacao`
* `/video`
* `/imagens`
* `/poster`
* `/demo`

Inclua apenas materiais produzidos pela equipe ou com permissão de uso.
