# Dados do Projeto

Mantenha neste diretório os dados utilizados no projeto, ou instruções de como obtê-los, quando não for possível ou adequado versioná-los no Git (por tamanho, licença ou sensibilidade).

## Sugestão de organização

* `/raw` — Dados brutos, como coletados/obtidos originalmente (idealmente não versionados se forem grandes).
* `/processed` — Dados tratados/transformados, prontos para uso em análises ou modelos.
* `/external` — Dados ou referências externas (ex.: bases públicas, dicionários, tabelas auxiliares).

Adapte essa organização conforme a natureza do seu projeto.

## Descreva neste arquivo

* Origem dos dados (coletados pela equipe, dataset público, base fornecida pela disciplina etc.) e, se aplicável, link ou instruções para obtê-los.
* Licença ou autorização de uso dos dados.
* Se há dados pessoais ou sensíveis envolvidos, e como isso é tratado (anonimização, agregação etc.).
* Um dicionário de dados (nome das colunas/campos, tipo, descrição), quando fizer sentido.

Se os dados forem grandes demais para o Git ou não puderem ser redistribuídos, versione apenas uma amostra, um script para baixá-los/gerá-los, ou instruções claras de acesso.
